|= Feature |= system |= dev-data |

| **Mount** | Automount | Persistent |

| **PRE** | None | DB dump, Docker stop |
| **POST_BACKUP** | Recovery keys | Docker start + Keys |
| **Verify Impact** | N/A | 0 (online) |

|= Security Aspect |= system |= dev-data |
| **Unmount after backup** | ✅ Yes | ❌ No (persistent) |
| **Physical power-off** | ✅ Yes (Shelly) | ❌ No (internal) |
| **Air Gap between backups** | ✅ TRUE | ❌ None |
| **Ransomware protection** | ✅ High | ⚠️ Lower |
| **Malware access** | ✅ Blocked | ⚠️ Possible |
| **Security Level** | Maximum | Convenience trade-off |

**Key Innovations (v2.5.0)**
- **POST_BACKUP phase**: Services restart BEFORE verify
- **Segment 05**: Active (triggers automount)
- **Segment 11**: Universal spindown (hdparm -y)
- **Segment 12**: Universal with error tolerance (|| true)
- **Air Gap Security**: True offline backup (system profile)
- **98% downtime reduction** for dev-data profile
